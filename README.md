# 800+ Theme (All Theme At One Place)

More than 800 color themes in a single extension. Dark, light, high-contrast, AMOLED and more.

## Usage
Press `Ctrl+K Ctrl+T` (`Cmd+K Cmd+T` on macOS) and pick any theme from the list.
